# Monitoring Student

> La plateforme des encadreurs pour suivre les élèves, leurs travaux et leur progression.

**Demo en ligne :** https://ton-site.infinityfreeapp.com
**Stack :** HTML, CSS, JavaScript Vanilla, Supabase

---

### ✨ Fonctionnalités
- Suivi des élèves par encadreur
- Gestion des travaux / tâches
- Suivi de la progression
- Dashboard encadreur
- Authentification via Supabase

### 🛠️ Tech Stack
- Frontend: HTML / CSS / JS
- Backend / BDD: Supabase (PostgreSQL)
- Hébergement: InfinityFree
